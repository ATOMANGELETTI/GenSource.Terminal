# skills/

Portable, on-demand Agent Skills — Cursor loads each
`.cursor/skills/<name>/SKILL.md` when relevant.

- **Naming**: `<name>/SKILL.md`, where `<name>` matches the `name` field in
  that file's frontmatter (1-64 chars, lowercase letters/numbers/hyphens).
- To create a new skill, use [`create-skill-pro`](create-skill-pro/SKILL.md).

## Skills in this project

- [`create-skill-pro`](create-skill-pro/SKILL.md) — scaffold and audit skills
- [`add-tauri-command`](add-tauri-command/SKILL.md) — add a Tauri command end-to-end
- [`add-react-page`](add-react-page/SKILL.md) — add a React page under `src/app/pages/`
- [`fill-placeholder`](fill-placeholder/SKILL.md) — fill empty template files safely
